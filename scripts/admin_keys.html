How Quota & Automatic Failover Work: Google's Gemini REST API does not expose a direct remaining-credit lookup endpoint. This dedicated monitor combines live HTTP probes (200 ready, 429 RESOURCE_EXHAUSTED parsed quotaMetric / quotaValue, or 403 invalid) with per-key daily request & token tracking against your configured daily RPD cap. During extraction, if the active key exhausts its quota (429) or fails auth, fetch_jobs.py automatically marks it in cooldown and fails over to the next enabled key by priority.
